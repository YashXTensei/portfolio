01 · About

From rating graphs
to running servers.

I started competitive programming the way most people start a new sport — badly, then obsessively. Every wrong answer on Codeforces taught me something a tutorial never could: how to think before I type.

Somewhere around my 300th problem, I realized the same instinct that helps me debug a failing test case on CF — break it down, isolate the failure, fix the root cause — is exactly what full-stack development rewards. So I picked up Django, started shipping real applications, and stopped treating "competitive programmer" and "developer" as two different identities.

Today I split my time between climbing the Codeforces ladder and building tools — like the one below — that turn CP grind into something measurable and improvable.
